# Decision log

One file per decision a future maintainer could reasonably undo by accident.
Same format as `charcha-web/docs/decisions/`; the web's ADRs still apply to the
product (rooms, vocabulary, anonymity) and are referenced, not copied.

`NNNN-short-title.md`, numbered in order, never renumbered. Each has
**Status**, **Date**, **Context**, **Decision**, **Consequences**. A decision is
never edited to say something different — write a new one and mark the old one
superseded.
